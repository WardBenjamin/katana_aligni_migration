# Katana Migration

Workspace for moving our MRP/ERP from [Aligni](https://www.aligni.com/) to [Katana](https://katanamrp.com/).

Local only: this git repo has no remote and never leaves this Mac.

- `docs/HANDOFF.md`: where the work stands. Start here.
- `docs/`: plans, research and final docs, one folder per topic.
- `scratchpad/`: dated task folders with scripts, data pulls and outputs.
- `src/`: reusable code promoted from the scratchpad.
- `repos/`: clean copies of product repos. Never edited.
- `worktrees/`: where product code changes happen, one worktree per branch.

The full layout and working rules are in `CLAUDE.md`.
